## 📋 Sobre o Projeto

O **Churrascômetro** é uma aplicação web simples que calcula automaticamente a quantidade de itens necessários para um churrasco com base no número de adultos, crianças e duração do evento.

### Regras de cálculo:

| Item | Até 6 horas | Acima de 6 horas |
|------|-------------|------------------|
| **Carne** | 400g por adulto | 650g por adulto |
| **Cerveja** | 1,2L por adulto | 2L por adulto |
| **Bebidas** (refri/água) | 1L por adulto | 1,5L por adulto |

> Crianças contam como **meia porção** (exceto cerveja).
